## Было изуенно
1. Абстрактный класс нужен для создания класса как шаблона для наследников
2. Дочерний класс переопределяет метод именяя метод родителя
3. Переменная типа родителя может хранить объект любого наследника
4. Аннотация @override используется для перверки того, что метод есть в родителе

## Ответы на вопросы
1. Абстрактный класс - это класс, который используется как шаблон для классов наследников. Character() нельзя написать напрямую, так как он не имеет реализации, наследники должны его переопределить
2. super передает данные из коструктора дочернего в родительский класс. Если убрать super произойдет ошибка компиляции.
3. @override у attack() переопределяет абстрактный метод, а в takeDamage() @override переопределяет метод с готовой реализацией. takeDamage() переопределяется так, как у Warrior добавляется armor.
4. Эта концепция называется полиморфизмом. Примером из Flutter служит child и children у виджетов.
5. _random с нижним подчёркиванием означает, что метод является приватным.
